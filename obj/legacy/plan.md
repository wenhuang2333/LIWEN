# 一、核心必选功能

这是最基础的底层能力，**必须优先实现**：

## 1. 全类型 HTTP 请求发送

支持 Postman 所有标准请求方法（HTTP 规范）：

- `GET`（查询数据）
- `POST`（提交数据）
- `PUT`（修改数据）
- `DELETE`（删除数据）
- `PATCH`（局部修改）
- `HEAD`（仅获取响应头）
- `OPTIONS`（跨域预检）

> Python 技术：用 `requests` / `httpx` 库实现，这是 Python 发送 HTTP 请求的标准库。

## 2. 请求地址与基础配置

- 输入框填写 **请求 URL**（支持 http/https）
- 配置 **请求超时时间**
- 控制 **是否自动重定向**
- 控制 **是否忽略 SSL 证书错误**（本地测试常用）

## 3. 响应结果展示（核心反馈）

Postman 的核心价值就是清晰展示响应，必须实现：

- 显示 **HTTP 状态码**（200/404/500 等）
- 显示 **响应耗时**、**响应大小**
- 展示 **响应头**（键值对）
- 展示 **响应体**（自动格式化）
- 异常处理：网络错误、无效 URL、请求失败的提示

# 二、常用增强功能（90% 用户高频使用）

实现这些，你的工具就和 Postman 基础版完全一致了：

## 1. 请求参数配置

1. URL 查询参数（Params）

   

   键值对输入，自动拼接在 URL 后（

   ```
   ?key=value
   ```

   ）

2. 请求头（Headers）

   

   自定义请求头（

   ```
   Content-Type
   ```

   、

   ```
   Authorization
   ```

    等）

3. 请求体（Body）【最重要】

   

   支持 Postman 全部 4 种格式：

   - `x-www-form-urlencoded`：普通表单
   - `form-data`：表单 + **文件上传**
   - `raw`：纯文本（JSON/XML/Text/HTML）
   - `binary`：二进制文件

   

## 2. 身份认证（Authorization）

支持接口常用鉴权方式：

- API Key（请求头 / 参数携带）
- Bearer Token（JWT 常用）
- Basic Auth（基础认证）
- Digest Auth（摘要认证）

## 3. 数据持久化（不用重复写请求）

- **请求历史记录**：保存最近发送的所有请求，一键重发
- **收藏 / 保存请求**：自定义名称、分类，保存常用接口
- **导出 / 导入**：把请求配置导出为 JSON 文件

## 4. 变量系统（提升效率）

- **全局变量**：统一配置域名（`{{baseUrl}}`）、Token
- **环境变量**：测试环境 / 正式环境快速切换
- 支持请求中用 `{{变量名}}` 动态替换参数

------

# 三、进阶专业功能（媲美专业版 Postman）

适合做完整工具，可选实现：

1. 接口自动化测试

   

   断言响应结果（判断状态码、响应体字段是否符合预期）

2. Cookie 管理

   

   自动保存、携带、编辑 Cookie

3. 批量请求

   

   批量运行多个接口，生成测试报告

4. WebSocket 请求

   

   支持 WebSocket 连接测试（Postman 新版核心功能）

5. 代理配置

   

   支持 HTTP/HTTPS 代理抓包

6. 响应预览

   

   HTML 响应直接渲染页面
