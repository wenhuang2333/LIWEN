## 1. 这是什么

**帽兜工具**（英文名 **LIWEN Tool**）是一款面向 Windows 的桌面工具箱（基于 PyQt6，同时可在 macOS / Linux 上运行，
VPN 隧道等功能除外），把 8 大类实用能力收进同一个深色界面：

| 分类 | 功能 |
|---|---|
| 🖥 本机 | 压缩解压、磁盘空间索引 |
| 🌐 局域网 | 文件传输、联机大厅（含 VPN 隧道 + 语音） |
| ☁️ 互联网 | 可视化网页爬虫、HTTP 请求发送、生成式 AI 对话 |
| ⚙️ 设置 | 个性化设置、故障检测与一键修复 |
| ℹ️ 关于 | 版本与作者信息 |

界面标题栏为自绘（无系统边框），顶部显示 logo 与「帽兜工具」，右下角可拖拽缩放。
主题为 Catppuccin Mocha 风格的深色配色，**强调色可切换**（默认蓝 / 紫 / 绿 / 橙 / 红）。

## 3. 功能详解

### 3.1 压缩解压

**能力**：把文件/文件夹打包为多种归档格式，或解压、预览归档内容。

**支持的格式**

| 格式 | 扩展名 | 压缩 | 解压 | 密码 | 分卷 |
|---|---|:--:|:--:|:--:|:--:|
| ZIP | `.zip` | ✅ | ✅ | ✅（AES） | — |
| 7z | `.7z` | ✅ | ✅ | ✅ | ✅ |
| TAR | `.tar` | ✅ | ✅ | — | — |
| TAR.GZ | `.tar.gz` `.tgz` | ✅ | ✅ | — | — |
| TAR.BZ2 | `.tar.bz2` `.tbz2` | ✅ | ✅ | — | — |
| TAR.XZ | `.tar.xz` `.txz` | — | ✅ | — | — |
| SHISHAN | `.shishan` | — | ✅ | ✅ | — |
| ZHANS（阵格式） | `.zhans` | ✅ | ✅ | ✅ | — |

**专有压缩刻度（0–10 级）**

这是本工具的特色机制。刻度 **0 = 标准输出**，**1–10 = 启用自研压缩策略**：

- 0 级：产出标准格式文件，可被 WinRAR / 7-Zip / `unzip` 等通用工具直接打开
- 1–10 级：启用**去重**（按内容哈希跳过重复数据块）、**逐文件 zlib 策略选择**、
  可选的**自定义种子码**，并把结果封装进 `.zhans` 容器

> ⚠️ **重要**：等级 > 0 时，即使选择了 ZIP/7z/TAR，产物实际是 `.zhans` 容器
> （文件头为 `ZHA\x01`），**通用工具无法打开**，需用本工具解压。
> 需要标准压缩包时请把等级设为 0。

**其它特性**

- **逐文件独立设置**：列表中每个文件可单独指定格式、输出路径、密码、分卷大小
- **归档预览**：表格展示归档内容（名称/大小/压缩后大小），支持选择性提取单个文件
- **分卷压缩**：仅 7z 支持
- **自定义种子码**：仅 `.zhans` 格式，用于产出可复现的定制压缩结果

---

### 3.2 空间索引

**能力**：扫描磁盘，可视化分析空间占用。

- 选择盘符/根路径后扫描，扫描在后台线程进行，带进度条
- **条形图**：以横向条形图展示占用最大的前 80 项
- **树形视图**：可排序列（名称 / 大小 / 占比 / 项目数），逐级展开、按需加载
- 结果持久化到 SQLite（`data/space_index_<盘符>.db`），**可反复查询无需重扫**
- 扫描分三阶段：收集文件与目录 → 自底向上汇总目录大小 → 写入目录条目

> 缓存文件可安全删除，删除后需重新扫描。占用空间可能较大（实测可达数 GB）。

---

### 3.3 局域网传输

**能力**：在同网段设备间直接收发文件，无需服务器。

- **发送模式**：自动发现局域网在线设备，或手动输入 IP；支持 ping 连通性检查
- **接收模式**：开启监听后广播自身，等待其他设备发送
- **自动压缩**：发送前自动打包为临时 ZIP 以提高小文件传输效率，接收端自动解压并清理临时文件
- **请求确认**：接收方会收到确认弹窗，可接受或拒绝；设置中可开启「自动接收」跳过确认
- 传输时可设置发送者昵称，接收端可看到来源

**技术要点**：TCP 传输（默认 12345），UDP 广播发现（12346）。

---

### 3.4 联机大厅（房间 / VPN / 语音）

用于让多台设备像在同一个局域网内一样联机游戏。有三种形态：

| 形态 | 说明 |
|---|---|
| **LobbyView（大厅）** | 创建房间（房间名、密码、虚拟子网）、扫描局域网已有房间、已保存房间列表 |
| **RoomPage（直连房间）** | 无 VPN 时的降级模式：基于真实局域网 IP 通信，支持语音 |
| **VpnPage（VPN 房间）** | 完整隧道模式：为每台设备分配 `10.99.0.0/16` 虚拟 IP，可跨网段联机 |

**VPN 模式的依赖与降级**

VPN 需要两个可选组件：Rust 编写的 `lan_vpn` 核心 与 Windows 驱动 `wintun.dll`。
两者缺一不可：

- 组件齐备 → 进入 `VpnPage`，展示虚拟 IP、在线对端、实时流量统计（200ms 刷新）
- 组件缺失 → 自动降级到 `RoomPage`，并显示安装指引，**程序不会崩溃**

VPN 启动需要管理员权限，程序会通过 UAC 主动申请提权。
停止 VPN 后有 1.5 秒冷却，等待 Windows 销毁 TUN 适配器。

**语音通话**

- 局域网 UDP 广播实现全双工语音，无需服务器
- 参数：16 bit 单声道、22050 Hz、20ms/帧、200ms 抖动缓冲
- 依赖 PyAudio；未安装时语音功能自动禁用（可在故障检测页一键安装）

**房间协议**

- UDP 12347 广播房间公告
- TCP 12347 处理加入请求，采用**挑战-应答认证**（`SHA256(密码哈希 + 随机数)`），密码不裸传
- 心跳间隔 3 秒，超时 10 秒判定对端离线

### 3.5 可视化网页爬虫

**能力**：不写代码，通过点击网页元素生成抓取规则。

**配置流程**

1. 内嵌 Chromium 浏览器打开目标网址
2. **元素拾取模式**：鼠标悬停高亮，点击捕获该元素的 **CSS 选择器 + XPath + 文本**
   （选中元素显示绿色高亮，所有匹配元素显示黄色，按 `Esc` 退出拾取）
3. 配置字段抽取规则（字段名 + 选择器 + 类型），右侧实时预览抽取结果
4. 配置翻页：下一页选择器 或 URL 规律（如 `?page={n}`）
5. 设置反爬选项：请求间隔、超时、重试次数、User-Agent、代理
6. 选择**调试模式**（少量页面验证）或**完整爬取**
7. 结果以表格预览，可导出（含 Excel）

**站点可行性检测**

爬取前可先检测目标站点：robots.txt 规则、是否需要 JavaScript 渲染、
是否有 CAPTCHA、Cloudflare 等反爬/CDN 特征，并给出可行性报告。

> 内嵌浏览器**仅用于可视化配置**。实际爬取由 `requests` + `lxml` 执行，速度更快。

### 3.6 请求发送（HTTP 调试）

类 Postman 的 HTTP 调试工具。

- **方法**：GET / POST / PUT / DELETE / PATCH / HEAD / OPTIONS / TRACE
- **URL**：自动补全 `http://`
- **Params 标签**：查询参数键值表
- **Headers 标签**：键值表，支持批量粘贴解析
- **Body 标签**，5 种模式：
  - `none` — 无请求体
  - `form-data` — 表单（含文件上传）
  - `x-www-form-urlencoded` — 表单编码
  - `raw` — 原始文本（JSON 编辑器，带格式化/校验按钮）
  - `binary` — 二进制文件
- **响应区**：状态码、耗时、大小；响应头 / Cookie 分区展示
- **历史记录**：自动保存请求历史，可收藏为集合
- **变量**：支持 `{{变量名}}` 占位替换，变量可持久化

### 3.9 故障检测与修复

**两种检测模式**

| 模式 | 覆盖范围 |
|---|---|
| **局域网检测** | 网卡接口、子网冲突、端口 12345/12346/12347 占用、UDP 广播能力、设备发现、房间扫描、PyAudio 与语音协议可用性 |
| **基础检测** | 压缩模块可用性、配置文件完整性、空间索引（sqlite3、可写性、扫描引擎、缓存完整性）、AI 功能（requests、API 配置、端点可达性、会话存储）、请求发送（requests/urllib、worker、页面、历史、变量、基础连通性） |

「全局检查」会串行执行两套检测。

**两种修复方式**

1. **一键修复** —— 在当前进程内执行修复，完成后自动重跑检测验证结果
2. **进行修复** —— 把问题序列化为 `repair_task.json`，启动独立的
   `LIWENTool_Repair` 修复程序，主程序退出；修复完成后修复程序重新拉起主程序

**可修复项**：释放被占端口、安装 PyAudio、修复配置文件、重置空间索引数据库、
重置 AI 配置、修复对话存储、修复请求历史、重置 HTTP 变量。

通过文件锁避免多个修复实例同时运行。

## 4. 命令行（CLI）

程序**带任何参数启动即进入 CLI 模式，不加载图形界面**，因此启动极快，适合脚本与自动化。

```bash
python code/main.py <命令> [参数...]
```

### 4.2 常用示例

```bash
# 查看全部命令
python code/main.py --help

# 压缩为 7z（标准包，等级 0）
python code/main.py compress ./docs -o docs.7z -f 7z -l 0

# 使用专有压缩刻度 + 密码
python code/main.py compress ./docs -o docs.zhans -f zhans -l 7 -p 123456

# 解压
python code/main.py decompress docs.7z -d ./out

# 查看归档内容
python code/main.py preview docs.7z

# 发送文件到局域网设备
python code/main.py lan-send -H 192.168.1.20 ./report.pdf

# 发 HTTP 请求
python code/main.py http-request -X POST --url https://httpbin.org/post \
    --headers '{"Content-Type":"application/json"}' \
    --body-type raw --body '{"a":1}'

# 爬取并导出
python code/main.py crawl --url https://example.com \
    --fields '[{"name":"标题","selector":"h1","type":"css"}]' -o result.xlsx

# 查看设置
python code/main.py settings-list
```

## 5. 端口与协议速查

| 用途 | 端口 | 协议 |
|---|---|---|
| 文件传输 | 12345 | TCP |
| 设备发现广播 | 12346 | UDP |
| 房间公告 / 发现 | 12347 | UDP |
| 加入房间 | 12347 | TCP |
| 房间语音 | 12400–12799（由房间端口推导） | UDP 单播 |
| 本地 Mock API 服务器 | 8700 | HTTP |

**语音参数**：22050 Hz、单声道、16 bit、20 ms/帧、200 ms 抖动缓冲。

> 与房间发现端口冲突，导致房主一侧语音无法启动。现由
> `voice_port_for_room(room_port)` 从 12400–12799 区间推导，同一房间内所有
> 参与者算出的端口一致，无需额外协商，并已避开 12345 / 12346 / 12347。

## 8. 已知限制

1. **等级 > 0 的压缩产物非标准格式**：会被封装为 `.zhans` 容器，
   通用解压工具无法打开，需用本工具解压。需要标准格式请用等级 0。
2. **TAR.XZ 与 SHISHAN 仅支持解压**，不支持压缩。
3. **密码支持不统一**：TAR 系列（tar / tar.gz / tar.bz2 / tar.xz）不支持密码；
   仅 ZIP、7z、SHISHAN、ZHANS 支持。
4. **分卷压缩仅 7z 支持**，产物命名为 `<文件名>.7z.001`、`.002` …；
   解压时选择第一个分卷（或主文件名）即可。
5. **VPN 隧道仅 Windows**，且需要 `lan_vpn` 核心与 `wintun.dll` 同时具备 + 管理员权限。
   安装包现已自动包含 `wintun.dll`；若从源码运行且缺少该文件，可执行
   `python code/tools/fetch_wintun.py` 自动获取官方驱动（带 SHA-256 校验）。
6. **空间索引缓存可能非常大**（取决于磁盘容量），建议定期清理或在故障检测页重置。
7. **爬虫尊重目标站点规则**，请自行确认合规使用。

## 9.1 版本 4.16.1 的稳定性改进（用户可感知）

本轮只修缺陷、不改功能，但以下变化用户能直接感受到：

1. **「开始监听」不再崩溃**，且监听期间界面不再每 4 秒卡顿一次。
   「扫描设备」按钮现在能真正发现同网段的其它设备。

   而不是提示"压缩完成（0 B / 0 个文件）"。
5. **损坏的压缩包会说明原因**（密码错误 / 已损坏 / 需要密码），
   预览窗口也会给出提示而不是空白表格；解压失败不会留下半截文件。

   语音播放也不再只播出一小部分（此前约 84% 的音频被丢弃）。

9. **爬虫长任务不再无限占用内存**：数据表最多显示 2000 行，
   导出内容仍完整；停止后立刻重开不会出现状态错乱。
10. **空间索引取消/重扫不再卡死进度条**，扫描中断会明确提示。
11. 无写权限的环境（只读配置目录）下程序仍能启动，配置自动降级到
    用户主目录或临时目录。

## 10. 术语表

| 术语 | 含义 |
|---|---|
| **阵格式 / ZHANS** | 本工具自研归档格式（`.zhans`），支持去重、逐文件压缩策略、可选种子码 |
| **SHISHAN** | 早期自研格式（`.shishan`），现已只读（仅支持解压） |
| **专有压缩刻度** | 0–10 级压缩等级，0 为标准输出，1–10 启用自研压缩策略并封装 `.zhans` |
| **种子码** | 自定义参数种子，使 `.zhans` 压缩结果可复现/定制 |
| **空间索引** | 扫描并持久化磁盘文件大小信息，支持快速查询占用 |
| **联机大厅** | 让多设备像同一局域网一样联机的房间系统 |
| **直连房间** | 无 VPN 的降级模式，走真实局域网 IP |
| **VPN 房间** | 通过 TUN 虚拟网卡组建虚拟局域网（10.99.0.0/16） |
| **故障检测** | 内置自检系统，覆盖网络、压缩、配置、索引、AI 等模块 |
